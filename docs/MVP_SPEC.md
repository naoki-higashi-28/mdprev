# mdprev MVP仕様書

## 1. 概要

指定ディレクトリ配下の **ディレクトリ構造とMarkdownファイル** を、ブラウザで快適にプレビューするローカルツール。

**GitHub Flavored Markdown（GFM）** を基本とし、**KaTeX（数式）** の描画に対応する。

---

## 2. アーキテクチャ

```
┌─────────────────────────────────────────────┐
│  Browser (React / Vite)                     │
│  ┌──────────┐  ┌─────────────────────────┐  │
│  │ ツリー    │  │ Markdownプレビュー      │  │
│  │ (左ペイン)│  │ (右ペイン)              │  │
│  └──────────┘  └─────────────────────────┘  │
└──────────────┬──────────────────────────────┘
               │ HTTP
┌──────────────▼──────────────────────────────┐
│  Go HTTP Server                             │
│  /api/tree  /api/file  /raw/<path>          │
│  + web/dist 静的配信                         │
└─────────────────────────────────────────────┘
```

- **バックエンド**: Go（ローカルHTTPサーバ）
- **フロントエンド**: React（Vite）→ `web/dist` を Go が静的配信
- **CDN依存なし**（オフライン環境で動作）

---

## 3. リポジトリ構成

```
/cmd/mdprev/        # Goエントリポイント（main.go）
/internal/
  /server/          # HTTPサーバ・ルーティング
  /tree/            # ディレクトリ走査
  /security/        # パス正規化・ルート外アクセス防止
/web/               # React（Vite）プロジェクト
/web/dist/          # ビルド成果物（.gitignore対象）
/docs/              # 仕様書等
```

## 4. CLI仕様

### 起動コマンド

```
mdprev [root]
```

- `root` 省略時はカレントディレクトリ

### オプション

| オプション | デフォルト | 説明 |
|---|---|---|
| `--host` | `127.0.0.1` | バインドするホスト |
| `--port` | `8080` | 待ち受けポート |

### 起動時の出力

```
mdprev serving /path/to/root on http://127.0.0.1:8080
```

## 5. API仕様

### 5.1 `GET /api/tree`

ルート配下のディレクトリ・ファイル一覧を返す。

- **Query**: `path`（任意、デフォルト `""`＝ルート直下）
- **Response**: `application/json`
- **ソート順**: ディレクトリ優先、名前昇順（大文字小文字無視）
- **除外対象**: `.` で始まるファイル・ディレクトリ（隠しファイル）

```json
{
  "path": "",
  "entries": [
    { "type": "dir",  "name": "docs", "path": "docs" },
    { "type": "file", "name": "README.md", "path": "README.md", "ext": "md", "size": 1234, "mtime": 1700000000 }
  ]
}
```

全件一括取得（遅延ロードはMVP対象外）。

### 5.2 `GET /api/file?path=...`

Markdownファイルの原文を返す。

- **Query**: `path`（必須、ルート相対パス）
- **Response**: `text/plain; charset=utf-8`
- **対象拡張子**: `.md`, `.markdown`
- **エラー**:
  - パスがルート外 → `403 Forbidden`
  - ファイルが存在しない → `404 Not Found`
  - 対象外の拡張子 → `400 Bad Request`

### 5.3 `GET /raw/<path>`

画像などのファイルをそのまま返す。

- **Response**: ファイルのMIMEタイプに応じた `Content-Type`
- **対象拡張子**: `png`, `jpg`, `jpeg`, `gif`, `svg`, `webp`
- **エラー**:
  - パスがルート外 → `403 Forbidden`
  - ファイルが存在しない → `404 Not Found`

### 5.4 静的ファイル配信

- `web/dist/` の内容をルート `/` で配信
- API・rawパス以外のリクエストは `index.html` にフォールバック

## 6. セキュリティ

### ルート外アクセス禁止（必須）

- すべてのファイルアクセスAPIで、リクエストされたパスを正規化し、ルートディレクトリの外に出ないことを検証する
- `..` を含むパスの正規化（`filepath.Clean` → `filepath.Abs` → `strings.HasPrefix`）
- **シンボリックリンク**: `filepath.EvalSymlinks` で実パスを解決し、ルート外なら拒否

### Content-Type

- `/api/*` レスポンスには適切な `Content-Type` を設定
- `/raw/` は拡張子からMIMEタイプを推定

## 7. フロントエンド仕様

### 7.1 技術スタック

| 用途 | ライブラリ |
|---|---|
| ビルド | Vite |
| UI | React |
| Markdown | `react-markdown` + `remark-gfm` + `rehype-raw`（※raw無効時は不要） |
| 数式 | `remark-math` + `rehype-katex` |
| コードブロック | MVP時点ではスタイリングのみ（ハイライトなし） |

### 7.2 レイアウト

```
┌──────────────────────────────────────────┐
│  パスバー: docs/guide.md      [コピー]    │
├────────────┬─────────────────────────────┤
│            │                             │
│  ツリー     │   Markdownプレビュー         │
│  (左ペイン) │   (右ペイン)                │
│            │                             │
│  docs/     │   # Guide                   │
│   ├ a.md   │   本文...                   │
│   └ b.md   │                             │
│  README.md │                             │
│            │                             │
├────────────┴─────────────────────────────┤
└──────────────────────────────────────────┘
```

### 7.3 ツリー（左ペイン）

- ルート配下のディレクトリ・ファイルをツリー表示
- ディレクトリはクリックで展開/折りたたみ
- ファイルクリックで右ペインにプレビュー表示
- 表示対象: ディレクトリおよび Markdownファイル（`.md`, `.markdown`）

### 7.4 プレビュー（右ペイン）

- GFM Markdownをレンダリング
- 数式（KaTeX）をレンダリング
- 生HTMLはレンダリングしない（MVP）

### 7.5 パスバー

- 現在表示中のファイルの相対パスを表示
- コピーボタンでクリップボードにコピー

### 7.6 URL連動

- `?path=relative/path.md` で直接表示
- ファイル選択時に `?path=` を更新

## 8. Markdown仕様

### 8.1 GFM対応範囲

| 要素 | 対応 |
|---|---|
| 見出し (`#`) | o |
| リスト（箇条書き・番号付き） | o |
| 引用 (`>`) | o |
| リンク | o |
| 画像 (`![](...)`) | o |
| テーブル | o |
| タスクリスト (`- [x]`) | o |
| 打ち消し線 (`~~`) | o |
| fenced code block (` ``` `) | o |
| 生HTML | x（MVP対象外） |

### 8.2 数式（KaTeX）

- インライン: `$...$`
- ブロック: `$$...$$`
- `remark-math` でパースし `rehype-katex` でレンダリング

### 8.3 リンク・画像のパス解決

| 種類 | 処理 |
|---|---|
| 相対パス画像 (`![](./img.png)`) | `/raw/<現在のディレクトリからの解決パス>` に変換 |
| 相対パスMDリンク (`[link](./other.md)`) | アプリ内遷移（`?path=` を更新） |
| 外部URL (`https://...`) | 通常リンクとして `target="_blank"` で開く |

---

## 9. エラーハンドリング

| ケース | 挙動 |
|---|---|
| 存在しないパスを `?path=` で指定 | プレビュー領域に「ファイルが見つかりません」表示 |
| ルート外パスへのAPIリクエスト | `403 Forbidden` を返す |
| バイナリファイルを `/api/file` で要求 | `400 Bad Request` を返す |
| ツリー取得失敗 | ツリー領域にエラーメッセージ表示 |

## 10. MVP対象外（将来対応）

以下はMVPには含めず、後続フェーズで対応する。

| 機能 | 備考 |
|---|---|
| SSE（ファイル変更監視・自動更新） | 手動リロードで代替 |
| Mermaid描画 | DOM後処理が必要で工数大 |
| コードハイライト（Shiki / Prism） | スタイリングのみで代替 |
| `--allow-html` オプション | 生HTML常時無効 |
| `--ignore` / `.mdprevignore` | 隠しファイル除外のみ |
| `--open`（ブラウザ自動起動） | URL表示で代替 |
| `embed` によるバイナリ同梱 | ディスクから配信 |
| 遅延ロード（ツリー） | 全件一括取得 |
| 履歴連動（戻る/進む） | `?path=` 直接指定のみ |
| ファイルサイズ上限制御 | 制限なし |
